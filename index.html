Detect pipe leaks early. Isolate the section. Alert on mobile.

A single-branch smart water model that watches pressure at two points (S1 → S2). When the difference stays above 15 kPa for 3 seconds, the system confirms a leak, closes the solenoid valve, and can notify the operator via ESP32.

ΔP

Differential pressure

Two sensors measure the drop along one pipe section. A leak between them lowers downstream pressure.

⏱

False-alarm filter

A 3-second confirmation window ignores short pump spikes before the valve is closed.

☎

Mobile alert add-on

ESP32 can send an SMS-style warning to a saved operator number when a leak is confirmed.

How the Arduino decides

Same steps as the live demo and the physical prototype.

Read S1 and S2

Average 20 ADC samples and convert to kPa.

Compute difference

ΔP = S1 − S2. A healthy short pipe only loses a few kPa.

Confirm for 3 seconds

If ΔP stays above 15 kPa for 3 s, the leak is confirmed.

Isolate and alert

Alarm + close the NC solenoid valve. Optional ESP32 mobile message.

On stage the leak is created with a ball valve (leak tap) between S1 and S2 — the pipe is never cut.
