How the Arduino decides

  1. Reads S1 and S2, averages 20 samples, converts to kPa.
  2. Computes difference: S1 − S2. Healthy pipe loses only a few kPa.
  3. If difference stays above 15 kPa for 3 seconds, leak is confirmed.
  4. Red LED + buzzer + LCD. Relay cuts power to the NC valve → it shuts. Alarm latched until reset.
  5. Optional ESP32 forwards the same event to Telegram / Blynk.
